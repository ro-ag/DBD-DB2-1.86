"# DBD-DB2-1.86" 

This a Fix of DBD::DB2 cpan module, is been tested on Windows 10 64 bits.

The module connects and do normal queries over the DB2 10.* versions.


Instructions: 

 - Clone or Download
 - Unzip
 - Run;
    - Perl MakeFile.PL
    - gmake
    - gmake test
    - gmake install
